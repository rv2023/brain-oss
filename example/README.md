# Example project

A tiny made-up project used by the README walkthrough and the tests. It has the four kinds of source Brain imports:

| Path | What it is |
|---|---|
| `DECISIONS.md` | A running decisions log (one decision per line, dated by heading) |
| `records/decisions/` | Structured decision records (`DEC-NNNN.yaml`), one fact per record |
| `plans/stage-map.yaml` | The story list: each story's stage, dependencies and the decisions it relies on |
| `logs/` | Code-review logs (`rv<round>-<org>_<repo>__<pr>.log`) and a merge review (`merge-review-<repo>-<pr>.md`) |

Everything here is invented; the IDs (`STORY-101`, `DEC-0002`, ...) only exist to show how items link.
